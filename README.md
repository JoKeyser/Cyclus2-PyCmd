# Cyclus2 cmd

Idea: A command-line interface to interactively send (near) real-time commands to [Cyclus2 ergometers](https://www.cyclus2.com/en/).

> [!warning]
> 🚧 This is prototyping in progress; not really usable yet. 🚧

## Description

The idea of this project is to create a command-line interface to interactively send (near) real-time commands to a [Cyclus2 ergometer](https://www.cyclus2.com/en/) by RBM elektronik-automation GmbH.

Cyclus2 ergometers offer a command interface that can be accessed over a serial interface or Ethernet, or WiFi.
Via that interface, you can request data and/or send commands in (near) real-time.
This project creates a simple Python-based command-line interface for interactive exploration.
Eventually, this can serve as a starting point for more sophisticated programming with the Cyclus2.
